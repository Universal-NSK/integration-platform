### Проверка сети
profile

### Проверка дубликатов
После получения списка сущностей из источника для начала необходимо проверить на дубликаты. Для этого пригодятся методы:  
crm.item.list?entityTypeId=1 для лидов  
crm.item.list?entityTypeId=4 для компаний  
crm.item.list?entityTypeId=1050 для групп компаний (для получения id типа сущности можно использовать crm.type.get?id=10&select[]=*&filter[title]="Группа компаний" или crm.type.list, если не известен bitrix_id класса)  
Можно также использовать entityTypeId=1&filter[id]=258&select[]=id для получения просто id, чтобы не тащить все поля  

### Сбор и составление полей
Для того, чтобы получить поля сущности CRM можно использовать методы   
crm.item.fields?entityTypeId=1 для получения полей лида  
crm.item.fields?entityTypeId=4 компании  
crm.item.fields?entityTypeId=1050 группы компаний
